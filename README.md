# 扫雷 · Minesweeper

一个支持手机和电脑的扫雷小游戏。

**[开始游戏](https://woshimaxfive.github.io/Minesweeper/)**

## 玩法

- 轻点打开格子，长按插旗；也可以切换到插旗模式，直接点按标记。
- 电脑右键插旗，方向键移动，回车或空格操作，F 插旗。
- 数字表示周围八格的雷数。周围旗数等于数字时，点击数字可以连开；旗插错了也可能踩雷。
- 第一次点击及其周围八格安全，打开所有安全格子即获胜。
- 拖动查看大棋盘，双指或使用 ＋ / − 缩放。

## 功能

- 初级、中级、高级和自定义棋盘。
- 浅色与深色主题。
- 自动保存进度、暂停和最佳用时。
- 完成首次缓存后支持离线游玩；支持的浏览器可添加到桌面。

经典随机棋盘，部分局面需要猜测。进度仅保存在当前浏览器，清除站点数据会删除存档和成绩。

## 本地运行

在项目目录执行 `python -m http.server 8081`，然后打开 <http://localhost:8081/>。
