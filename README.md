# 扫雷 · Minesweeper

适用于手机和电脑的扫雷。

**[开始游戏](https://woshimaxfive.github.io/Minesweeper/)**

## 玩法

- 轻点开格，长按插旗；插旗模式下轻点标记，再点取消。
- 电脑右键插旗，方向键移动，回车或空格操作，F 插旗。
- 数字表示周围八格的雷数。周围旗数等于数字时，点数字连开其余邻格；旗插错也可能踩雷。
- 首点及相邻格安全，打开所有安全格即通关。
- 拖动查看大棋盘，双指或 ＋ / − 缩放。

## 功能

- 初级、中级、高级和自定义棋盘。
- 全屏与横屏布局；浏览器支持时进入系统全屏，否则铺满页面、横向显示。
- 经典随机可能需要猜测；无猜支持初级、中级，可按数字推理通关。
- 浅色与深色主题。
- 底部开格、插旗、暂停；顶部切换横屏和全屏，设置内换主题、查说明、重开。
- 通关或踩雷后显示结果，可收起面板查看完整棋盘。
- 结算后点“再试这盘”：保留雷位和第一步，重置后续操作与计时，计为练习局。
- 练习提示标出一个确定的安全格或雷、相关数字及理由，由玩家操作；推不出结论时会说明。
- 自动保存进度和最佳用时，支持暂停。
- 设置和结算页可查战绩：按正式／练习、玩法和棋盘分别统计局数、通关数、胜率与最佳用时。两类各保留最近 50 局，通关刷新成绩时提示新纪录。
- 首次缓存后可离线游玩，支持的浏览器可添加到桌面。

无猜在首点生成棋盘，须先开格再插旗；判断错误仍可能踩雷。两种玩法的最佳用时分开记录。

进度和成绩保存在当前浏览器，清除站点数据会一并删除。

仅统计通关和踩雷，中途重开不计。练习不影响正式成绩；设置内重试练习仍是同盘，点“新一局”或重选难度则开始正式局。旧累计成绩保留，逐局历史从战绩功能上线后记录。

## 本地运行

在项目目录运行 `python -m http.server 8081`，打开 <http://localhost:8081/>。

`src/` 存放游戏代码，`assets/` 存放样式和图标；根目录保留网页、安装清单和离线入口。
