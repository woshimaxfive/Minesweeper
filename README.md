# 扫雷 · Minesweeper

一个支持手机和电脑的扫雷小游戏。

**[开始游戏](https://woshimaxfive.github.io/Minesweeper/)**

## 玩法

- 轻点打开格子，长按插旗；也可以切换到插旗模式，直接点按标记。
- 电脑右键插旗，方向键移动，回车或空格操作，F 插旗。
- 数字表示周围八格的雷数。周围旗数等于数字时，点击数字可以连开；旗插错了也可能踩雷。
- 第一次点击及其周围八格安全，打开所有安全格子即获胜。
- 拖动查看大棋盘，双指或使用 ＋ / − 缩放。

## 功能

- 初级、中级、高级和自定义棋盘。
- 棋盘全屏与横屏布局；支持的浏览器可进入系统全屏，其他浏览器仍可铺满页面、横向显示。
- 经典随机与无猜玩法；无猜支持初级、中级，棋盘可通过线索推理通关。
- 浅色与深色主题。
- 自动保存进度、暂停和最佳用时。
- 完成首次缓存后支持离线游玩；支持的浏览器可添加到桌面。

经典随机棋盘可能需要猜测。无猜模式在首次开格时准备棋盘，先开格再插旗；判断错误仍然会踩雷。两种玩法分别记录最佳用时。

进度仅保存在当前浏览器，清除站点数据会删除存档和成绩。

## 本地运行

在项目目录执行 `python -m http.server 8081`，然后打开 <http://localhost:8081/>。

游戏代码位于 `src/`，样式和图标位于 `assets/`。根目录保留网页入口、安装清单和离线入口。
